# [영어과교육론1] 그룹 수업 실연 자동 조편성 웹 애플리케이션

본 웹 애플리케이션은 **'영어과교육론1'** 강의에서 진행되는 **그룹 수업 실연**을 위해 실시간 학생 접속, 성별 균형 배정, 4대 언어기능 매칭, 역할 분배, 시각적 셔플 연출 및 PDF/CSV 다운로드를 지원하는 맞춤형 시스템입니다.

---

## 🚀 빠른 시작 (실행 방법)

```bash
# 1. 의존성 패키지 설치
npm install

# 2. 서버 실행
npm start
```

서버 실행 후 브라우저에서 아래 주소로 접속합니다:
- **교수자 대시보드 (스크린 프로젝터용)**: [http://localhost:3000](http://localhost:3000)
- **학생 모바일 접속 페이지**: [http://localhost:3000/join](http://localhost:3000/join)

---

## ✨ 핵심 기능 및 알고리즘 규칙

### 1. 실시간 학생 접속 및 QR 코드
- 교수자 화면에 참여용 **QR 코드**와 접속 주소가 자동으로 표시됩니다.
- 학생들은 스마트폰으로 QR 코드를 스캔하여 **학번, 성별(남/여), 이름**을 입력해 접속합니다.
- 교수자 화면에 실시간으로 접속 학생 수와 성비, 명단이 즉각 동기화됩니다.
- 필요 시 교수자가 학생을 **수동 추가/삭제**하거나 **모의 학생(19명)** 데이터를 1초 만에 로드할 수 있습니다.

### 2. 4인/3인 그룹 크기 자동 분할
- 기본 **4인 1조**로 구성되며, 총 인원이 4로 나누어 떨어지지 않는 경우 **3인 조**를 유연하게 생성합니다.
  - *예시: 19명 $\rightarrow$ 4인 4개조 + 3인 1개조 (총 5개조)*
  - *예시: 18명 $\rightarrow$ 4인 3개조 + 3인 2개조 (총 5개조)*

### 3. 성별 균형 배정
- 남학생 수가 적은 경우 1개조에 남학생이 1명씩 우선 편성되고, 남학생 비율이 높으면 2명씩 균등 분배됩니다.

### 4. 4대 기능 및 실연 주차 배정 (조 단위)
- 각 조별로 4대 언어기능이 균등(1:1:1:1)하게 배정됩니다:
  - **이해기능 - 듣기** : 13주차
  - **이해기능 - 읽기** : 13주차
  - **표현기능 - 말하기** : 14주차
  - **표현기능 - 쓰기** : 14주차

### 5. 조 내 세부 역할 자동 배정 (학생 단위)
- **4인 조**: 
  - `도입 및 정리 활동` (1명)
  - `활동 1` (1명)
  - `활동 2` (1명)
  - `활동 3` (1명)
- **3인 조**: 도입 및 정리 제외
  - `활동 1` (1명)
  - `활동 2` (1명)
  - `활동 3` (1명)

### 6. 인터랙션 및 결과 내보내기
- **셔플 애니메이션**: 스크린 투사 시 학생들의 몰입감을 높이는 룰렛/슬롯 셔플 연출 및 축하 컨페티 효과.
- **드래그 앤 드롭**: 자동 배정 후 교수자가 학생 카드를 마우스로 끌어 다른 조로 이동하거나 역할을 수정 가능.
- **결과 내려받기 (PDF & CSV)**: 
  - **PDF 다운로드**: 고품질 A4 맞춤형 결과표 (과목명, 조별 기능, 주차, 학생 명단 및 역할 명시, 한글 완벽 지원).
  - **CSV 다운로드**: 엑셀에서 바로 열 수 있는 UTF-8 호환 스프레드시트 파일.
